# InstaDe-tox

A lightweight browser extension (Manifest V3) that removes algorithmic feeds, reels, and explore recommendations from Instagram Web to curb distraction.

---

## Features

- **Reels Blocker:** Automatically hides short-form video feeds and infinite scroll reels.
- **Explore Suppressor:** Disables algorithmic recommendation tabs.
- **Zero Overhead:** Pure vanilla JavaScript DOM mutations with no third-party libraries or background resource drain.
- **Privacy-Focused:** Runs locally in the browser with no telemetry or external network calls.

---

## Installation (Developer Mode)

1. Clone or download this repository:
   ```bash
   git clone https://github.com/devsanthoshmk/InstaDe-tox.git
   ```
2. Open Chrome (or any Chromium-based browser) and navigate to `chrome://extensions`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the `InstaDe-tox` root folder.
5. Navigate to `instagram.com` to use the distraction-free interface.

---

## Tech Stack

- **Specification:** Chrome Extensions Manifest V3
- **Language:** Vanilla JavaScript, CSS Selectors
